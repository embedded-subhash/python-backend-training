# Employee Management Console Application

## Project Overview

The Employee Management Console Application is a Python-based command-line application used to manage employee records efficiently. The application allows users to perform various employee management operations such as adding, viewing, searching, updating, and deleting employee details.

The project is developed using core Python concepts including functions, lists, dictionaries, loops, conditional statements, and exception handling.

## Features

* Add Employee
* View All Employees
* Search Employee by ID
* Update Employee Details
* Delete Employee
* Input Validation
* Exception Handling
* Menu-Driven Interface

## Employee Details Stored

Each employee record contains:

* Employee ID
* Name
* Email
* Department
* Salary
* Experience

```bash

```

### Step 2: Navigate to Project Directory

```bash

```

### Step 3: Run the Application

```bash

```
